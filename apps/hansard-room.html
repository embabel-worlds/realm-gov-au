A deliberately bounded workflow

Search, select, ask

01 · Discover

Search the live record

ParlInfo phrase search covers Chamber Hansard, committees and Estimates, grouped so an empty class stays meaningful.

02 · Index

Choose a working set

Indexing is opt-in. It fetches at most two recent matches per class and stores them under stable record identities.

03 · Ask

Retrieve, judge, answer

Agentic RAG searches only that working set, exposes its verbatim evidence and states when the excerpts are insufficient.

Coverage and interpretation limits
  • Questions on Notice are not yet a searchable record class.
  • Live phrase results are capped at eight recent matches per class.
  • Indexing is capped at six records per phrase. It is a working set, not a Parliament-wide mirror.
  • An empty result never supports “Parliament did not discuss this”. It only describes the searched class or indexed set.
Sources: ParlInfo search feeds and record pages (Australian Parliament, aph.gov.au).
