The virtual traversal

One query joins register, place and election facts

Virtual Cypher materialises the requested GrantConnect window only when the relationship is traversed. An optional ai.relevant stage can judge which awards are about your subject before their delivery postcodes join to the seeded geographic and election reference data.

MATCH (w:GrantWindow {
  key: $from + '|' + $to
})-[:PUBLISHED_GRANT]->(g:GrantAward)
WHERE g.value >= $minimum
  // This line is added only when a subject is supplied:
  AND ai.relevant(g, '<your subject>')
WITH g
// This ordering is likewise added only for a subject:
ORDER BY ai.score(g, '<your subject>') DESC
MATCH (e:Electorate)
WHERE g.deliveryPostcode IN e.postcodes
RETURN e.division, e.member,
       e.heldByAbbrev, e.marginBand,
       collect({
         award: g.gaId,
         recipient: g.recipient,
         activity: g.activity,
         value: g.value
       }) AS grants,
       sum(g.value) AS total
The join is deterministic. No model chooses an electorate or infers a motive. The map marker is the median of a division’s postcode centroids and may be nudged for legibility in dense cities; it is not an official boundary centroid.

How it works

1. The data

Grants come from GrantConnect's published-awards export, read by this realm (gov-au) as GrantWindow -[:PUBLISHED_GRANT]-> GrantAward (producer grantsPublishedByDate). The window key is the inclusive date range YYYY-MM-DD|YYYY-MM-DD; the export file for it is downloaded on first use and cached for six hours, so results are as of the last download. Electorates (Electorate: the 150 divisions, member, holding party, 2025 two-party-preferred margin and the postcodes whose GeoNames centroid lies inside the AEC 2025 boundary) are reference data seeded with the realm; they change only when the realm does. GrantConnect caps an export at 50,000 rows and says so in the file; the realm reports that as truncation.

2. The questions

The app makes one call: the lens below, with from, to, minValue and topic from the form. The lens runs the grant query and the electorate query together, then in its script maps each grant's delivery postcode to divisions, sums by division and margin band, and counts exclusions.

au-grant-hop (lens) — published grants mapped by delivery postcode to 2025 electorates and their margins.

Lens au-grant-hop, run through the app runtime (runner.lens). $windowKey is from|to. With no topic the first query is used and the minimum value is applied in the script. With a topic, the second is used: ai.relevant keeps awards a model judges to be about the topic, ai.score orders them, and $semanticFloor is 90% of the minimum.

Grants in the window (no topic)

MATCH (w:GrantWindow {key:$windowKey})-[:PUBLISHED_GRANT]->(g:GrantAward)
RETURN g.agency AS agency, g.recipient AS recipient, g.program AS program, g.activity AS activity,
       g.value AS value, g.deliveryPostcode AS deliveryPostcode,
       g.deliveryState AS deliveryState, g.selectionProcess AS selectionProcess,
       g.publishDate AS publishDate, g.gaId AS gaId, g.goId AS goId

Grants in the window (with a topic)

MATCH (w:GrantWindow {key:$windowKey})-[:PUBLISHED_GRANT]->(g:GrantAward)
WHERE g.value >= $semanticFloor
  AND ai.relevant(g, '${criterion}')
RETURN g.agency AS agency, g.recipient AS recipient, g.program AS program, g.activity AS activity,
       g.value AS value, g.deliveryPostcode AS deliveryPostcode,
       g.deliveryState AS deliveryState, g.selectionProcess AS selectionProcess,
       g.publishDate AS publishDate, g.gaId AS gaId, g.goId AS goId
ORDER BY ai.score(g, '${criterion}') DESC

Electorates

MATCH (e:Electorate)
RETURN e.division AS division, e.state AS state, e.marginBand AS marginBand,
       e.marginPct AS marginPct, e.heldByAbbrev AS heldByAbbrev, e.member AS member,
       e.centroidLat AS centroidLat, e.centroidLon AS centroidLon,
       e.postcodes AS postcodes

3. When it looks wrong

  • A division with no grants means no award with a single-division delivery postcode landed there. Grants whose postcode is blank, matches no division, or straddles several divisions are excluded from money totals and counted in Results.
  • An empty map ("No result divisions") means nothing in the result mapped to exactly one division; change the range or minimum.
  • With a topic, an award the model judged off-topic is left out; the topic is a model judgement, not a GrantConnect category.
  • Status PARTIAL (for example a capped export) is shown as a notice above the results; FAILED means the export could not be read, and the operation panel offers a retry.
  • A long or uncached range can take minutes the first time and is fast for six hours after.

4. What made this possible

  • No grants database: matching the window node makes the appliance download exactly that GrantConnect export and share it from a file cache.
  • The topic filter is a function inside the Cypher query (ai.relevant), applied to rows already scoped by date and value, rather than a separate classification job.
  • The geographic join is deterministic reference data; no model chooses an electorate.
